# Product Hunt

**Name:** spar
**Tagline** (60 characters max): Make Claude and ChatGPT argue until the answer is right
**Topics:** Artificial Intelligence, Developer Tools, Open Source, Productivity

**Description:**
Ask anything. Claude answers, ChatGPT finds what's wrong and fixes it, back and forth until one of them can't find a hole. You steer on any turn and watch each one work, live. It uses the Claude and ChatGPT plans you already pay for, with no API keys. Free and open source in your terminal; the desktop app adds projects, your chat history and a safe code mode.

**Maker comment:**
I build public art and run a construction-tech company, which means a lot of applications and technical writing. Two AIs reviewing each other catch far more than either alone, so I stopped copy-pasting between them and built spar. I'd love to know what you use it for.

# Answers for the comments

**Isn't this against Anthropic's or OpenAI's terms?**
spar runs the official, unmodified Claude Code and Codex CLIs, signed in by you, on your own computer, the same as typing the commands yourself. It never touches your credentials. Check each provider's current terms for your own use.

**Why not just use one model twice?**
Different models have different blind spots. The same model reviewing itself tends to agree with itself.

**Don't they just agree with each other?**
That's what the house rules are for: be right, not agreeable; PASS only when nothing important is left; no busywork changes. Without the rules, they do politely agree.

**How is this different from council or second-opinion plugins?**
Those make one agent the boss and ask the others for opinions. In spar, neither is in charge: they take turns as equals, and you referee. It also works for anything, not just code.

**Does it cost anything?**
No. It uses the Claude and ChatGPT plans you already have, and each turn counts against that plan's usage like normal.

**Gemini?**
Google doesn't allow its consumer sign-in in third-party tools, so the CLI sticks to Claude and ChatGPT. The desktop app supports Gemini with an API key.

**What's the catch / business model?**
The CLI is free and stays free. There's a paid desktop app with projects, your imported chat history, a safe code mode with undo, and pay-as-you-go credits for hundreds of other models.
